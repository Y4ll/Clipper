Bienvenido a Clipper

Arrastra un video o pega un link (YouTube, Kick…). Clipper encuentra los mejores momentos y te los deja en vertical. Revisas, cortas y descargas.

Si Windows bloquea Clipper al abrirlo: clic en Más información → Ejecutar de todas formas, o añade una exclusión en Seguridad de Windows. Pasa porque el programa no tiene firma digital (es de pago); no hace nada raro y todo se procesa en tu PC.

6. YouTube

Opciones de subida

Cómo configurarlo

Usa la API oficial de Google con tu cuenta. Una sola vez: en console.cloud.google.com crea un proyecto, activa «YouTube Data API v3» y crea una credencial «ID de cliente de OAuth» tipo App de escritorio; pega aquí el ID y el secreto. Empieza en «Privado» para probar.

Subir muchos clips repetidos de un mismo streamer puede hacer que YouTube marque el canal. Usa solo contenido tuyo o con permiso.
