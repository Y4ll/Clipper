# Clipper

App local para sacar clips verticales (9:16) de videos largos: detecta los momentos con más audio, aplica zoom/vibración y texto gancho. Gratis y sin marca de agua.

## Descargar el .exe (Windows)
1. Pestaña **Actions** → última ejecución de *Build Clipper.exe*.
2. Baja el artifact **Clipper-Windows** (zip con `Clipper.exe` y `ffmpeg.exe`).
3. Descomprime y abre `Clipper.exe`. Se abre una página en tu navegador.

## Con Python
Necesitas Python 3 y ffmpeg: `python clipper_app.py` (o `--lan` para usarlo desde el celular en la misma wifi).
